# Mercari Women’s Shoe Resale Analysis

This project analyzes women’s shoe listings from the Mercari Price Suggestion Challenge dataset.

The goal is to compare shoe brands fairly by adjusting prices for shoe type and item condition, then classify brands into Value, Mid-Market, and Premium resale tiers.

## Progress

- Completed initial data exploration
- Cleaned the women’s shoe dataset
- Selected seven major shoe categories
- Created condition analysis groups
- Calculated peer-adjusted listing prices
- Assigned eligible brands to resale price tiers
